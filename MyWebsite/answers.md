# Assignment Answers

## Q1. What meta tag is used to change the page character encoding?

```html
<meta charset="UTF-8">
```

**Answer:**
This tag sets the character encoding of the webpage. It allows the browser to correctly display Arabic, English, and many other languages.

## Q2. What are the benefits of the Meta Description tag? How is it related to SEO?

**Answer:**

### Benefits:
- Gives a short description of the webpage.
- Helps search engines understand the page.
- Appears in search results.
- Encourages users to visit the website.

### Relation to SEO:
- Improves the appearance of search results.
- Can increase the click-through rate (CTR).
- Supports SEO indirectly by attracting more visitors.
